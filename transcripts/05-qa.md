### Security, emails and design (highlights)
- **Security:**
  - All 8 member endpoints return 401 when logged out, with a fake cookie, and with an expired session.
  - All 7 admin endpoints return 401 logged out and 403 for a member.
  - Member A gets 404 when reading, cancelling or leaving member B's items. The response is identical to a non-existent id, and the data is unchanged.
  - Login gives the same response for an unknown email and a wrong password, at the same speed (20.7 ms vs 20.8 ms median).
  - Cookie is `HttpOnly; SameSite=Lax`, with `Secure` in production. Sessions last 30 days for members and 12 hours for admins.
  - Reset tokens are stored hashed, valid for 1 hour, and single-use. A reset logs the user out on every device.
- **Emails:**
  - E5 has the correct "You cancelled" / "The studio cancelled" wording.
  - E8 reached both admins, and only for the paid booking.
  - E6 went only to confirmed members, and none for price- or capacity-only changes.
